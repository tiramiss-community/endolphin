# Endolphin の機能

この一覧は正式リリース `2026.9.1-endolphin.0` 時点で、利用者とサーバー運営者が画面から使える機能を用途別に紹介します。内部 API の全操作や、利用者向け画面を持たない保守用機能は列挙対象に含めません。アカウントの権限やサーバー運営者の設定によって、一部の機能が表示されないことがあります。

## 投稿とタイムライン

- **ノート** — テキストや画像などを投稿します。公開範囲、CW（内容を隠す設定）、予約投稿、アンケート、添付ファイルを設定できます。
- **返信・リノート・引用** — 会話に返信したり、ノートを再共有したり、コメントを付けて引用したりできます。
- **リアクション** — ノートに絵文字で反応できます。サーバーのカスタム絵文字も利用できます。
- **タイムライン** — ホーム、ローカル、ソーシャルなどのタイムラインでノートを読みます。ピン留めされたノートや検索も利用できます。
- **通知** — 返信、リアクション、フォローなどの通知を受け取ります。Web Push に対応する環境ではブラウザー通知も設定できます。
- **下書き** — 投稿の作成中の内容を保存し、後から編集できます。

## 人や話題を見つける

- **プロフィールとフォロー** — プロフィールを設定し、ユーザーをフォローします。フォロー申請が必要なアカウントでは申請を送ります。
- **検索・ハッシュタグ** — ノートやユーザー、ハッシュタグを探します。サーバーで利用できるトレンド表示もあります。
- **ブロック・ミュート** — 見たくない相手やリノートを個別に非表示にします。会話単位で通知を抑える設定もあります。
- **ユーザータグ** — ユーザーに付いたタグから、同じタグの利用者を見つけます。ハッシュタグがノートの話題を示すのに対し、ユーザータグは利用者を探すためのものです。
- **チャンネル** — 話題ごとの投稿場所です。チャンネルをフォローすると、そのチャンネルに投稿されたノートを追いやすくなります。全体のタイムラインとは別に、テーマを絞って交流したいときに使います。

## ノートを整理する

似た用途に見える機能も、集め方が異なります。

| 機能 | 何を集めるか | 使いどころ |
| --- | --- | --- |
| **リスト** | 自分で選んだユーザー | 見たい人をグループにして、その人たちの投稿を追う。 |
| **アンテナ** | 条件に合うノート | キーワードなどの条件を登録し、自動で集まるノートを確認する。 |
| **クリップ** | 自分で選んだノート | 後で読むノートやテーマ別のノートを保存してまとめる。 |
| **チャンネル** | 同じ話題の投稿 | 話題ごとに投稿・閲覧する場所をフォローする。 |

### リスト

リストは、フォロー中のユーザーなどから自分で選んだ人をまとめる機能です。リストを作り、メンバーを追加すると、そのメンバーのノートを専用のタイムラインで読めます。たとえば「開発仲間」「写真」など、ホームタイムラインを分けて見たいときに使います。条件に合うノートを自動収集する機能ではありません。

### アンテナ

アンテナは、登録した条件に合うノートを自動で集めます。キーワードなどを設定し、作成後はアンテナのタイムラインから結果を確認します。特定の言葉を含む投稿を追いたい場合に便利です。特定の人だけを読みたい場合はリストを使います。

### クリップ

クリップは、ノートを後から見返せるように保存してまとめる機能です。クリップを作成し、ノートのメニューから追加します。公開・非公開を選べるため、自分用のメモ代わりにも、他の人と共有するまとめにも使えます。ノートのお気に入り機能は削除されていますが、保存したノートを整理する用途にはクリップを利用できます。

### チャンネル

チャンネルは、利用者が特定のテーマについて投稿する場所です。チャンネル一覧から興味のあるものを開き、フォローして投稿や新着ノートを確認します。自分でフォロー対象を選ぶリストや、条件で投稿を拾うアンテナとは異なり、同じ話題の場をフォローして交流する使い方です。

## 複数の情報を並べて見る

### デッキ

デッキは、複数のタイムラインやウィジェットをカラムとして並べる画面です。カラムを追加して、ホームタイムライン、リスト、アンテナ、通知などを配置できます。更新を追いながら別の一覧も見たい場合に便利です。デッキのプロファイル同期を有効にすると、複数端末でプロファイルを共有できます。

## ミニアプリ

### Play（Flash）

Play は、Misskey の「Flash」と呼ばれるミニアプリを閲覧・作成する機能です。Play 一覧から作品を選び、各作品の画面で遊んだり動作を試したりできます。作成画面では対応するスクリプトや UI を組み合わせて作品を作り、公開できます。サーバーの設定や権限によって、作成・公開できる範囲は異なります。

Play（Flash）は、Endolphin で削除された **Games** とは別機能です。リバーシ、Drop and Fusion、Clicker などの Games は利用できません。

## ファイルとアカウント

- **ドライブ** — 画像などのファイルをアップロードし、フォルダーで整理します。投稿への添付やプロフィール画像の設定にも使います。
- **カスタム絵文字** — サーバーで提供されている絵文字をノートやリアクションで使えます。
- **プロフィール** — 表示名、自己紹介、アイコン、バナーなどを設定します。アバターデコレーションを利用できるサーバーでは、アイコンに装飾を付けられます。
- **アカウント設定** — プライバシー、通知、テーマ、表示、セキュリティなどを調整します。二要素認証やログイン中のアプリ管理にも対応します。
- **テーマ・ウィジェット・プラグイン** — 画面の見た目やホーム画面の表示をカスタマイズできます。プラグインは内容を理解し、信頼できるものだけを導入してください。
- **複数アカウント** — 対応ブラウザーではアカウントを切り替えて利用できます。
- **アプリ連携・データ管理** — API アプリや Webhook の連携、アカウントデータのインポート・エクスポート、設定のバックアップなどを行えます。

## サーバー運営者向け

- **招待・登録管理** — サーバーの登録方針に応じて、招待やアカウント登録を管理します。
- **ロール** — 条件に応じたロールを作成し、利用者へ権限や表示上の属性を付与します。
- **通報とモデレーション** — 利用者からの通報を確認し、必要に応じてアカウントや投稿への対応を行います。
- **連合管理** — 他サーバーとの接続状況を確認し、必要に応じてインスタンス単位の制御を行います。
- **アナウンス** — サーバー利用者へ運営からのお知らせを掲載します。
- **カスタム絵文字管理** — サーバーで使用するカスタム絵文字を追加・整理します。
- **サーバー設定・運用** — 登録方法、メールや外部サービス、ファイル、ジョブキューなどの設定・状態を管理します。

管理画面に表示される項目は、サーバーの設定と管理者権限によって異なります。削除済み機能については[本家 Misskey との違い](./differences.md)をご覧ください。
