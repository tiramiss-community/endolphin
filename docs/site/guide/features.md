# Endolphin の機能

Endolphin で利用できる機能を、使う場面ごとにご紹介します。内容は利用者とサーバー運営者が画面から使う機能を対象とし、内部 API の全操作や、利用者向け画面のない保守用機能は含みません。表示される項目は、アカウントの権限やサーバーの設定によって異なる場合があります。

## 投稿とタイムライン

- **ノート** — テキストや画像などを投稿できます。公開範囲や CW（内容を隠す設定）、予約投稿、アンケート、添付ファイルにも対応しています。
- **返信・リノート・引用** — 会話に返信したり、ノートを再共有したり、コメントを添えて引用したりできます。
- **リアクション** — 絵文字でノートに反応できます。サーバーで提供されているカスタム絵文字も使えます。
- **タイムライン** — ホーム、ローカル、ソーシャルなどのタイムラインでノートを読めます。ピン留めされたノートや検索も利用できます。
- **通知** — 返信やリアクション、フォローなどを通知で確認できます。対応する環境では Web Push によるブラウザー通知も設定できます。
- **下書き** — 作成中のノートを保存し、後から続きを編集できます。

## 人や話題を見つける

- **プロフィールとフォロー** — プロフィールを設定し、気になるユーザーをフォローできます。フォロー申請が必要なアカウントでは、申請を送れます。
- **検索・ハッシュタグ** — ノートやユーザー、ハッシュタグを検索できます。サーバーで利用できる場合は、トレンドも確認できます。
- **ブロック・ミュート** — 特定のユーザーやリノートを非表示にできます。会話ごとに通知を抑える設定もあります。
- **ユーザータグ** — ユーザーに付いたタグから、同じタグの利用者を探せます。ハッシュタグがノートの話題を示すのに対し、ユーザータグは利用者を見つける手がかりになります。
- **チャンネル** — 話題ごとの投稿場所です。チャンネルをフォローすると、その話題のノートを追いやすくなります。

## ノートを整理する

リスト、アンテナ、クリップ、チャンネルは、集める対象と使い方がそれぞれ異なります。

| 機能 | 集めるもの | 使う場面 |
| --- | --- | --- |
| **リスト** | 自分で選んだユーザー | 見たい人をグループにして、その人たちの投稿を読む。 |
| **アンテナ** | 条件に合うノート | キーワードなどを登録して、該当する投稿を自動で確認する。 |
| **クリップ** | 自分で選んだノート | 後で読み返したいノートや、テーマごとの投稿をまとめる。 |
| **チャンネル** | 同じ話題の投稿 | 話題ごとの場所をフォローし、投稿や閲覧をする。 |

### リスト

リストでは、フォロー中のユーザーなどから選んだ人をグループにできます。たとえば「開発仲間」「写真」のように分けておくと、それぞれの専用タイムラインで投稿を追えます。条件に合うノートを自動で集めたいときは、アンテナが便利です。

### アンテナ

アンテナは、登録した条件に合うノートを自動で集めます。キーワードなどを設定しておくと、専用のタイムラインから結果を確認できます。特定の人の投稿をまとめて読みたいときは、リストをご利用ください。

### クリップ

クリップは、ノートを後から読み返せるように保存してまとめる機能です。ノートのメニューからクリップへ追加でき、公開・非公開も選べます。自分用の読み返しリストにも、他の人と共有するまとめにもお使いいただけます。ノートのお気に入り機能はありませんが、保存したノートの整理にはクリップをご利用いただけます。

### チャンネル

チャンネルは、特定のテーマについて投稿する場所です。チャンネル一覧から興味のある場所をフォローすると、投稿や新着ノートを確認できます。ユーザーを選んで追うリストや、条件から投稿を集めるアンテナとは異なり、同じ話題の場所をフォローして交流できます。

## 複数の情報を並べて見る

### デッキ

デッキでは、複数のタイムラインやウィジェットをカラムとして並べられます。ホームタイムラインに加えて、リストやアンテナ、通知などを配置すると、複数の情報を一度に確認しやすくなります。デッキのプロファイル同期を有効にすると、複数端末で設定を共有できます。

## Play

Play では、公開されている作品を閲覧して試したり、ご自身の作品を作成・公開したりできます。サーバーの設定や権限によって、作成・公開できる範囲が異なる場合があります。

Play は、削除された Games とは別の機能です。リバーシ、Drop and Fusion、Clicker などの Games は利用できません。

## ファイルとアカウント

- **ドライブ** — 画像などのファイルをアップロードし、フォルダーで整理できます。ノートへの添付やプロフィール画像の設定にも使えます。
- **カスタム絵文字** — サーバーで提供されている絵文字を、ノートやリアクションで使えます。
- **プロフィール** — 表示名や自己紹介、アイコン、バナーなどを設定できます。サーバーで利用できる場合は、アイコンにアバターデコレーションを付けられます。
- **アカウント設定** — プライバシー、通知、テーマ、表示、セキュリティなどを調整できます。二要素認証やログイン中のアプリ管理にも対応しています。
- **テーマ・ウィジェット・プラグイン** — 画面の見た目やホーム画面をカスタマイズできます。プラグインは、内容を確認したうえで導入をご検討ください。
- **複数アカウント** — 対応するブラウザーでは、複数のアカウントを切り替えて利用できます。
- **アプリ連携・データ管理** — API アプリや Webhook の連携、アカウントデータのインポート・エクスポート、設定のバックアップなどを行えます。

## サーバー運営者向け

- **招待・登録管理** — サーバーの登録方針に応じて、招待やアカウント登録を管理できます。
- **ロール** — 条件に応じたロールを作成し、利用者へ権限や表示上の属性を付与できます。
- **通報とモデレーション** — 利用者からの通報を確認し、必要に応じてアカウントや投稿に対応できます。
- **連合管理** — 他サーバーとの接続状況を確認し、必要に応じてインスタンス単位の制御を行えます。
- **アナウンス** — サーバー利用者へ運営からのお知らせを掲載できます。
- **カスタム絵文字管理** — サーバーで使うカスタム絵文字を追加・整理できます。
- **サーバー設定・運用** — 登録方法、メールや外部サービス、ファイル、ジョブキューなどを設定・管理できます。

管理画面に表示される項目は、サーバーの設定や管理者権限によって異なります。削除された機能については[本家 Misskey との違い](./differences.md)にまとめています。

機能や対応状況はリリースによって変わることがあります。リリース情報は[最新リリース](https://github.com/tiramiss-community/endolphin/releases/latest)でご覧いただけます。
