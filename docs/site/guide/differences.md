# 本家 Misskey との違い

Endolphin は Misskey を基にしたフォークです。使い慣れた投稿やタイムライン、他サーバーとの連合を活かしながら、小規模なコミュニティで使う機能に絞っています。

## 残している機能

ノート、タイムライン、リアクション、ドライブ、通知、フォロー、リスト、アンテナ、クリップ、チャンネル、Play、デッキなどを利用できます。アカウント設定やテーマ、ウィジェットのカスタマイズも残しています。機能ごとの案内は[機能一覧](./features.md)にまとめています。

## 削除した機能

次の機能は Endolphin ではご利用いただけません。

| 削除した機能 | 補足 |
| --- | --- |
| ノートのお気に入り | ノートを後から見返す用途には、ノートをまとめて管理できるクリップをご利用いただけます。 |
| ページ、ギャラリー | ページの作成・公開や、ギャラリーへの投稿はできません。 |
| 実績 | 実績の獲得・表示には対応していません。 |
| Games | リバーシ、Drop and Fusion、Clicker などのゲーム機能はありません。Play とは別の機能です。 |
| 埋め込みコード生成 | ノートなどを外部サイトへ埋め込むコードの生成には対応していません。 |
| チャート | サーバー統計などをチャートで表示する画面はありません。 |
| チャット | ユーザー間のチャット機能はありません。 |
| 管理 DB 統計 | データベースのテーブル・インデックス統計を表示する管理画面はありません。 |
| リテンション分析 | 利用者の継続状況を分析する機能はありません。 |
| 広告・プロモーション | 広告やプロモーションの作成・掲載には対応していません。 |

## ActivityPub と API

ActivityPub による連合は本家 Misskey に準拠する方針で、Endolphin 独自の連合仕様には変更していません。削除した機能は連合オブジェクトではないため、機能整理によって連合の仕様は変わりません。

API の互換性は endpoint や schema の定義にも及び、削除した機能の定義も維持しています。ただし、機能が使えるわけではありません。削除機能の読み取り endpoint は空配列・`null`・既定値などを返し、書き込み endpoint は `FEATURE_REMOVED`（HTTP 410 Gone）を返します。API を利用するアプリや Bot では、削除対象 endpoint がこのような応答を返します。

機能や対応状況はリリースによって変わることがあります。リリース情報は[最新リリース](https://github.com/tiramiss-community/endolphin/releases/latest)でご覧いただけます。
