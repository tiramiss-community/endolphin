# 本家 Misskey との違い

Endolphin は Misskey を基にしたフォークです。使い慣れた投稿・タイムライン・連合の仕組みを活かしながら、小規模コミュニティで使う機能に絞っています。このページは正式リリース `2026.9.1-endolphin.0` 時点の違いを説明します。

## 残しているもの

機能の使い方は[機能一覧](./features.md)をご覧ください。

## 削除した機能

以下は Endolphin では利用できません。

| 削除した機能 | 補足 |
| --- | --- |
| ノートのお気に入り | ノートを後で見返す用途にはクリップを使えます。クリップはノートをまとめて管理できる別機能です。 |
| ページ、ギャラリー | ページの作成・公開や、ギャラリー投稿はできません。 |
| 実績 | 実績の獲得・表示はできません。 |
| Games | リバーシ、Drop and Fusion、Clicker などのゲーム機能はありません。Play（Flash）とは別の機能です。 |
| 埋め込みコード生成 | ノートなどを外部サイトへ埋め込むための機能はありません。 |
| チャート | サーバー統計などをチャートで見る画面はありません。 |
| チャット | ユーザー間のチャット機能はありません。ノートやチャンネルで交流してください。 |
| 管理 DB 統計 | データベースのテーブル・インデックス統計を表示する管理画面はありません。 |
| リテンション分析 | 利用者の継続状況を分析する機能はありません。 |
| 広告・プロモーション | 広告やプロモーションの作成・掲載機能はありません。 |

削除した機能と同じ名前の API endpoint が存在する場合も、機能が使えることを意味しません。互換性を保つため endpoint の登録や型を残しているものがあり、読み取りは空の値、書き込みは `FEATURE_REMOVED`（HTTP 410 Gone）を返す場合があります。

## ActivityPub と API

ActivityPub による連合は本家 Misskey に準拠する方針で、Endolphin 独自の連合仕様には変更していません。削除済み機能は連合オブジェクトではないため、機能整理と連合挙動は切り分けています。

削除機能を除き、Misskey REST API および misskey-js との互換性を保つ方針です。ただし、API の存在だけで削除機能が利用できるとは限りません。API を利用するアプリや Bot は、対象機能の有無と応答を確認してください。

## どの版を基準にしているか

この説明と[機能一覧](./features.md)は `2026.9.1-endolphin.0` を基準にしています。以降のリリースで変更された機能については、対象バージョンのリリース情報も確認してください。
