# Endolphin とは

Endolphin は、Misskey を基にした、お一人様から少人数のコミュニティ向けの軽量なフォークです。友人や趣味の仲間が集まる場で、ノートの投稿やタイムライン、ファイル共有、ActivityPub による他サーバーとの交流など、日々の利用に必要な機能を厳選して提供します。

名前は、かつての Misskey 派生プロジェクト [Dolphin](https://github.com/misskey-dev/dolphin) に着想を得ています。Dolphin のように機能を絞りながら、Misskey の使い慣れた操作や柔軟な画面構成も活かすことを目指しています。

## こんなコミュニティに

- 自分や知人のために小さなサーバーを運営したい
- 趣味や関心ごとを共有する場所がほしい
- 多機能な公開サーバーより、必要な機能を見つけやすい環境を選びたい
- デッキやリストなど、日々の情報整理はしっかり使いたい

大規模な公開インスタンスの運営、企業向けのサービス基盤、本家 Misskey のすべての機能を必要とする用途は想定していません。

## 「軽量」について

ここでいう軽量は、機能を厳選したプロダクト方針を指します。Endolphin が特定の人数やマシン構成で動作するという性能保証ではありません。実際に運用できる規模は、利用状況、サーバー構成、連合先、保存するファイル量などによって変わります。大きな公開コミュニティを計画している場合は、負荷を見積もり、必要に応じて構成やソフトウェアを選定してください。

## 本家 Misskey との関係

Endolphin は Misskey のコードを基に開発し、本家の更新を取り込みながら保守するフォークです。ActivityPub の連合挙動は本家に準拠し、削除した機能を除く Misskey REST API との互換性も維持する方針です。一方、すべての画面や機能を本家と同じように提供するものではありません。具体的な違いは[本家 Misskey との違い](./differences.md)をご覧ください。
