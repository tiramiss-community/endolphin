# Endolphin とは

Endolphin は、Misskey を基にした、お一人様から少人数のコミュニティに向けたフォークです。友人や趣味の仲間が集まる場所で、ノートの投稿やタイムライン、ファイル共有、ActivityPub による他サーバーとの交流などをお楽しみいただけます。

名前は、かつての Misskey 派生プロジェクト [Dolphin](https://github.com/misskey-dev/dolphin) に着想を得ています。機能を厳選しながら、Misskey の使い慣れた操作や、デッキなどの柔軟な画面構成を活かすことを目指しています。

## こんなコミュニティに向いています

- ご自身や知人のために、小さなサーバーを運営したい
- 趣味や関心ごとを共有する場所を作りたい
- 必要な機能を選びやすい環境で、落ち着いて交流したい
- リストやアンテナ、デッキを使って、見たい投稿を整理したい

大規模な公開インスタンスや企業向けのサービス基盤、本家 Misskey のすべての機能を必要とする用途は主な対象としていません。

## 「軽量」について

Endolphin の「軽量」は、機能を厳選するプロダクト方針を表しています。特定の人数やサーバー構成で動作するという性能保証ではありません。実際に運用できる規模は、利用状況やサーバー構成、連合先、保存するファイル量などによって変わります。

## 本家 Misskey との関係

Endolphin は Misskey のコードを基に開発し、本家の更新を取り込みながら保守しています。ActivityPub による連合は本家に準拠する方針です。削除した機能についても API endpoint や schema の定義を維持し、互換性を保つための応答を返します。ただし、その機能自体を利用できるわけではありません。削除した機能や API の詳細は、[本家 Misskey との違い](./differences.md)にまとめています。

機能や手順は更新に伴い変わることがあります。現在のリリース情報は[最新リリース](https://github.com/tiramiss-community/endolphin/releases/latest)でご覧いただけます。
