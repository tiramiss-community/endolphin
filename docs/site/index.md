# Endolphin ドキュメント

Endolphin のドキュメントへようこそ。Endolphin は、お一人様から少人数のコミュニティに向けて、日々の交流に使う機能を厳選した Misskey のフォークです。本家 Misskey に準拠した ActivityPub 連合を保ち、他のサーバーとのつながりも大切にしています。

ご自身や仲間の場所として Endolphin を知りたい方も、サーバー運営を始めたい方も、目的に合わせてご覧いただけます。

## Endolphin を知る

どんな機能があるか、本家 Misskey とどう違うかをご紹介します。
