# 検証記録

ここには特定時点に実施した検証の環境・結果・制約を保存する。現在使う手順は [再検証手順](../validation/README.md)、運用者向けの操作は [運用ガイド](../../site/setup/operations.md) を参照する。

## 保存規約

- ディレクトリ名は `YYYY-MM-DD-対象`。同日の別実施は識別子を追加する。Issue 番号は関連情報として記載する。
- 各記録の README に目的、実施日とタイムゾーン、対象 OS / architecture / アプリ版、対象ガイドと検証手順の commit 固定リンク、結果ファイルへのリンクを記載する。環境の詳細は environment.md に分けられる。
- ケースごとの `PASS / FAIL / SKIPPED`、根拠、失敗原因・対処・再検証結果、対象外と省略理由を残す。対象外の版や現在のガイドへ結果を一般化しない。
- 新しい実施は新しい記録として追加し、過去の結果を上書きしない。誤記の訂正は訂正理由を明記する。
- 秘密情報、DB dump、VM ディスク、生ログ、一時資材、起票用の下書きは保存しない。
