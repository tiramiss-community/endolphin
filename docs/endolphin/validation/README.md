# 再検証手順

ここには開発者が運用ガイドを繰り返し検証するための手順を置く。一時作業ディレクトリや Issue ごとの作業計画は置かない。

操作コマンドの正本は [運用ガイド](../../site/setup/operations.md) と方式別ガイド。ここでは環境準備、試験データ、失敗注入、確認項目、合格条件を定義し、運用コマンドのコピーは保守しない。

- [バックアップ・復元](./backup-restore.md): systemd / Docker の世代選定、正常復元、中断・失敗時の補償を隔離環境で検証する。

関連するガイドを変更する際は、対応する再検証手順も確認・更新する。実施結果は [検証記録](../validation-records/README.md) に保存し、ここに過去の PASS を蓄積しない。Issue / PR の下書きや一時資材はリポジトリに保存しない。
